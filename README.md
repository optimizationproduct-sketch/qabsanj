# قاب‌سنج

تحلیل و طراحی قاب فولادی سه‌بعدی با روش سختی مستقیم.

طراحی و تنظیم: یوسف بهرام‌بیگی

این برنامه یک ابزار آموزشی است: بارگذاری معادل استاتیکی استاندارد ۲۸۰۰ (ویرایش چهارم)، ترکیب‌بارهای مبحث ششم، و کنترل‌های مقاومتی و لرزه‌ای هم‌راستا با مبحث دهم / AISC. برای نقشه‌های مهرشده یا طراحی اجرایی کافی نیست؛ اتصال‌ها و چشمه اتصال مدل نمی‌شوند.

## اجرا

```bash
npm install
npm run dev
```

سپس مرورگر را روی پورت ۸۰۸۰ باز کنید.
